# Instrucciones para agentes — alejandroneri.github.io

Antes de crear o sugerir archivos de QA en Windows (checkouts, logs, evidencias, capturas, ZIP o análisis), es **obligatorio** leer [docs/QA_WORKSPACE.md](docs/QA_WORKSPACE.md).

Raíz única: `$HOME\QA-Workspace\Portafolio\repos\alejandroneri.github.io`. No crear carpetas de trabajo o artefactos de pruebas dispersos en `$HOME`, `Desktop`, `Downloads` o temporales externos.

Comprobar SHA y árbol Git antes de escribir. Preservar evidencias anteriores; no usar `git clean`, `reset --hard`, borrar ni mover archivos existentes sin autorización. Guardar evidencia por PR/SHA/ejecución y omitir secretos y datos reales. Esta política documental no autoriza cambios funcionales, despliegues ni merges.
